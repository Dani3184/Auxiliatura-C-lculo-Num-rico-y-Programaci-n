# Auxiliatura: Cálculo Numérico y Programación

Este repositorio contiene el material generado durante las clases de la auxiliatura. Aquí encontrarás códigos, ejemplos y ejercicios prácticos desarrollados a lo largo del semestre.

## Contenido

- Scripts y funciones en Python
- Ejemplos de los métodos avanzados en clases.
- Ejercicios resueltos y propuestos

## Requisitos

- Lenguaje/software: Python
- Opcional: Jupyter Notebook

## Uso

Clona el repositorio y explora las carpetas por tema. Cada archivo tiene comentarios internos explicando su funcionamiento.
